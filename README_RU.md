# Telegram AI Operator — стартовый комплект

## Что уже реализовано
- Отдельный обычный Telegram-аккаунт через Telethon (MTProto).
- Управляющий бот на aiogram.
- Белый список: отвечает только тем, кого добавил администратор.
- Команды включения/выключения и настройки инструкции ИИ.
- Groq API с OpenAI-совместимым интерфейсом.
- Краткий контекст последних сообщений считывается непосредственно из Telegram.
- Тексты переписок не записываются в Supabase и не сохраняются приложением.
- Supabase хранит только настройки и список разрешённых Telegram ID.
- HTTP `/health` для мониторинга хостинга.

## Важные ограничения
1. Это MVP, а не гарантированная production-система.
2. Бесплатные тарифы и квоты ИИ могут меняться; при исчерпании квоты ответы остановятся.
3. Не добавляй человека, пока не получил его явное информированное согласие на обработку переписки внешней ИИ-моделью. Такое согласие должно оставаться действующим и относиться к конкретному чату.
4. Не пересылай никому TELEGRAM_SESSION, BOT_TOKEN, GROQ_API_KEY или Supabase service-role key.
5. Не публикуй `.env` и не коммить секреты в GitHub.
6. В Supabase хранятся только настройки/разрешённые ID; содержимое сообщений не сохраняется.
7. При первом запуске проверь работу на тестовом аккаунте и с одним добровольным собеседником.

## Команды управляющего бота
- `/start`
- `/status`
- `/enable`
- `/disable`
- `/add @username`
- `/remove @username`
- `/list`
- `/prompt` — показать текущую инструкцию
- `/prompt новый текст инструкции` — заменить инструкцию

## Порядок настройки
1. Создай отдельного Telegram-бота через официального BotFather и сохрани BOT_TOKEN.
2. Узнай свой Telegram numeric ID и укажи его как ADMIN_ID.
3. Создай Telegram API application на `https://my.telegram.org` и получи API_ID + API_HASH.
4. Создай Groq API key на `https://console.groq.com/keys`.
5. Создай Supabase project. В SQL Editor выполни `database/schema.sql`.
6. В Supabase возьми Project URL и service_role key (не anon key). Храни ключ только в серверных secrets.
7. Локально установи Python 3.11+ и зависимости, затем запусти `python generate_session.py`.
8. Сгенерированную TELEGRAM_SESSION добавь в переменные окружения хостинга. Не отправляй её в ChatGPT или управляющий бот.
9. Разверни Docker-приложение на хостинге, который допускает постоянное соединение MTProto. Перед вводом секретов проверь актуальный статус безопасности и условия провайдера.
10. После запуска напиши управляющему боту `/status`, затем `/add @username`, проверь тестовый диалог и только после этого включи `/enable`.

## Примечание по Render Free
Render Free засыпает после периода отсутствия входящих запросов, не предоставляет постоянный диск и не гарантирует фоновые процессы 24/7. `/health` можно использовать для внешнего мониторинга, но пинги не являются гарантией SLA. Для постоянной работы нужен хостинг с непрерывным процессом и сохранением настроек в Supabase.
